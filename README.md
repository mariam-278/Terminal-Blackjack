# Terminal-Blackjack
A capstone to test the python concepts I have been learning recently.

## Overview
This is a blackjack game played in the terminal. It is regular blackjack, however there are some different rules:

- The card deck is infinite
- There are no jokers
- All face cards are equal to 10
- The ace is equal to 11 unless your total is above 21, then it will default to 1
- Computer is the dealer
- You will only have 1 opportunity to pull an extra card
- Computer will only pull a third card if it's score is less than 17

Please try it out and have fun!
